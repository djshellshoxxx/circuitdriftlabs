Developer notes

Keep allocation, blocking I/O and locks out of real-time callbacks. Prepare buffers and immutable configuration ahead of processing. Check denormal handling, parameter smoothing and state migration against actual target hosts.

API & SDK design record

A future shared SDK should specify sample formats, channel layout, buffer ownership, thread expectations, parameter units and reset behavior. This is a proposed documentation contract; no downloadable CDL SDK is claimed.

Release discipline

Use semantic versions for released interfaces and explicit compatibility notes. Project G-74 and the Challis Modification are narrative codenames, never substitutes for machine-readable versions. This collection starts at editorial revision 0.1; repository commits provide its change history.
