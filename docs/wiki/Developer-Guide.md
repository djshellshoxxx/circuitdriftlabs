# Developer Guide

- Preview locally: serve the folder (for example `python -m http.server 8000`) and open the homepage.
- The site is plain HTML, CSS and JavaScript (`index.html`, `styles.css`, `tools.css`, `site.js`, `products.js`). No build step.
- Art is generated by `tools/generate_art.py`, which writes original SVG drawings to `assets/`. It needs no fonts or image assets.
- There are no automated tests in the repository.
