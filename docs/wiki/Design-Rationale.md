# Design Rationale

Sources: `BRAND.md`, README "Site design", `docs/superpowers/specs/`.

- **Static site.** Hosted on GitHub Pages with no backend, so there is nothing to operate.
- **Original artwork.** The signal drawings are generated from code (`tools/generate_art.py`) rather than shipped as photos or fonts, which avoids licensing questions (*inferred from the script's docstring*).
- **Name.** "Circuit" points to the tools, "Drift" to things that move and change, and "Lab" to a place to test sounds. The brand notes record alternative names but not any trademark clearance.
- **One index of projects.** The homepage gathers the audio repositories so visitors can find them from one place (README).
- **Contextual links.** A design addendum covers linking between tools (`docs/superpowers/specs/2026-10-01-contextual-tool-links-addendum.md`).
