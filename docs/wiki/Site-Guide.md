# Site Guide

- **Browser tools** (homepage dropdown): TrackStats, Transposition Calculator, MIDItest, LoudnessBatch, PartyPosterGen.
- **Experiments:** Binaural Web Beats, BabbleForge.
- **Project index:** the homepage lists the audio repositories in the ecosystem, with live Pages builds where they exist.
- **Adding a release:** edit `products.js` (an array `window.CDL_PRODUCTS` with name, type and links), then check the homepage.
