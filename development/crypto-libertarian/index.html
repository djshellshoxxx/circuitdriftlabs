Experimental development wing

Crypto Libertarian

Open-source privacy and cryptographic tools for voluntary communities.

What this wing explores

Crypto Libertarian is a Circuit Drift Labs development wing for experimental software about privacy, cryptography and voluntary cooperation. Here, “crypto” means cryptographic technology; it does not imply a token, cryptocurrency or financial product.

FEATURED PROJECT

QuietVote

QuietVote is an experimental software artwork and documentation project exploring private decision-making for voluntary groups. Its specifications remain drafts; the implementation is unaudited and is not ready for real votes.

Demo status: a hosted browser demo is not live. The project is being prepared for a static client preview; there is no hosted voting server connected here.
