SIMD for multi-voice polyphonic synthesizers

Performance numbers are useful only with their conditions attached.

Choose the parallel dimension

Independent voices are a natural candidate for lane-wise processing. Feedback recurrences can constrain parallelism within a single voice. Compare a structure-of-arrays layout with the existing implementation before attributing gains to vector instructions.

Benchmark matrix

Run scalar and vector paths on the same machine at 44.1, 48 and 96 kHz, with 32, 64, 128 and 512 sample blocks. Sweep voice counts and modulation density. Record compiler, flags, CPU model, operating system, power mode, warm-up procedure and source revision.

Report correctness with speed

Report median, p95, p99 and maximum observed callback duration, deadline misses and numerical error against the reference. ARM and x86 results belong in separate tables. Do not infer end-to-end speedup from instruction width alone. Measurements have not yet been collected.
