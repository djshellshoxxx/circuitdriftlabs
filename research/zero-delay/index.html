Zero-delay feedback topologies

Solve the present sample without inventing a feedback delay.

The implicit problem

A feedback circuit discretization can yield F(y; x, s) = 0, where x is the current input and s holds previous state. Newton iteration takes yₖ₊₁ = yₖ − F(yₖ)/F′(yₖ) in the scalar case. A vector system requires solving a Jacobian system, rather than element-wise division.

Bounded iteration

Set absolute and relative residual thresholds, an iteration cap, finite-value checks and a documented fallback. Test abrupt parameter changes, high drive and silence. Convergence is conditional on the model and initialization; a zero-delay topology is not a blanket claim of zero processing latency.

Reference and further reading

The DAFx paper Resolving Grouped Nonlinearities in Wave Digital Filters using Iterative Techniques discusses Newton-based approaches. See also CDL-RFC-042 ↗.
